# Capstone_2

Business Analysis with Python
 
Sales territory analysis for **EmporiUm**, a fictional student bookstore chain that also sells tech gear, art supplies, and other products in-store and online. This project uses Python (pandas, NumPy, and Matplotlib) in a Jupyter Notebook to read, clean, merge, and analyze sales data across multiple CSV files, then presents the findings for a marketing manager audience.
 
## Assigned Territories
 
| Territory | Territory Manager | Region |
|-----------|-------------------|--------|
| South Carolina | Len Jensen | South |
| Texas | Jeff "Howdy" Richards | South |
 
Both territories sit within the **South** region, making this a same-region comparison.
 
## Project Overview
 
The marketing manager requested a full analysis comparing in store sales between the two assigned territories. The notebook walks through each business question step by step using markdown explanations alongside the code, so the manager can follow both the answers and the reasoning behind them.
 
Questions covered in the core analysis:
- Who manages each territory, and which stores fall under each one
- Monthly total in store revenue across the full data period
- Store by store sales ranking within each territory
- Top rewards customers per territory
- Transactions and revenue per month by product category
- Final recommendation on where to focus marketing in the next quarter
